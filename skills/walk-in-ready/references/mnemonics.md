# The eight types of memory hook

One hook per concept. Never two. Two hooks cancel each other out and both get lost.

## The cover test (apply to every hook before it ships)

Cover the definition. Read only the hook. Try to rebuild the concept: what it is, when it applies,
and what it predicts.

- Rebuilt it → the hook ships.
- Only recalled the *name* of the concept → the hook is decoration. Replace it.

A hook that names is a label. A hook that rebuilds is a tool.

---

## Type 1: Structural analogy (the strongest, use first)

Map the concept onto a system already known cold, so the *relationships* transfer, not just the word.

> Sunk cost is a fuel burn already spent. It does not appear anywhere in the go/no-go call for the
> next leg. Only remaining fuel and remaining distance vote.

Test: does the analogy predict the same edge cases the concept does? If it breaks at the edges, say
where it breaks, in one line.

## Type 2: The procedure

Steal an existing ordered checklist. Order is free memory. Best for anything with steps: valuation,
hypothesis testing, a five forces sweep.

> Run it like a preflight: you never skip an item because the last three were fine.

## Type 3: The counterexample that hurts

One vivid case where the intuitive answer is wrong. The sting is the storage.

> The 8 percent return fund that beat the market for nine years and then closed. It is not in the
> average because it stopped reporting. That absence *is* survivorship bias.

## Type 4: The two-word contrast pair

For neighbor concepts that get swapped under pressure. Always paired, never solo.

> Correlation moves together. Causation moves because.

## Type 5: The number anchor

Attach one real number from the reading to the concept. The number becomes the handle.

> The 30 percent that never renews. Every churn discussion starts there.

## Type 6: The place (method of loci)

Assign the concept to a physical spot on a walked route. Costs nothing to maintain, holds a sequence
of five to seven items very well. Pull the route from `my-setup.md`.

## Type 7: The say-it-out-loud line

The exact sentence spoken when the name is called. Written to be said, not read. Under 25 words,
opens with the claim, no throat clearing.

> "It is a fixed cost that already left the account, so it should not move the decision. What matters
> is the marginal cost from here."

## Type 8: The wrong-first-then-corrected

State the plausible wrong version, then correct it. This is what the podcast's curious host does, and
it is why the podcast works. Rehearsing the recovery is the point.

> "So bigger sample means bigger effect?" — No. Bigger sample means tighter estimate. The effect
> stays whatever it is. Precision, not size.

---

## Choosing

| Concept shape | Use |
| --- | --- |
| A system with moving parts | Type 1 |
| An ordered method | Type 2 |
| A counterintuitive result | Type 3 |
| Two things that get swapped | Type 4 |
| A statistic that anchors a debate | Type 5 |
| A list of five to seven | Type 6 |
| Anything likely to be cold called | Type 7, always, in addition to one other |
| The single hardest idea in the chapter | Type 8 |

Type 7 is the only one that can pair with another type, because it is a delivery format rather than a
storage format. Every core concept gets one Type 7 line plus exactly one storage hook.
